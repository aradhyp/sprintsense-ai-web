# SprintSense AI (Web Edition)

A fully client-side, interactive Agile Backlog estimation and prioritization tool. This version is designed specifically for immediate portfolio showcasing—it requires zero backend and can be hosted directly on **GitHub Pages** as a live website.

## Features
* **Zero Server Architecture:** Built entirely with pure HTML, Tailwind CSS (via CDN), and Vanilla JavaScript.
* **Instant Hosting:** Deployable directly via GitHub Pages in seconds.
* **Live Framework Analytics:** Dynamic, on-the-fly WSJF and RICE score generation.
* **Fibonacci Story Point Mapping:** Converts linear effort estimation to standard Agile capacity metrics in real-time.

## 🚀 How to Create Your Live Webpage

### Step 1: Push to GitHub
1. Create a new public repository on GitHub (e.g., `sprintsense-web`).
2. Upload the files from this folder (`index.html`, `script.js`, `README.md`) directly into the repository.
3. Commit your changes.

### Step 2: Enable GitHub Pages (Free Hosting)
1. In your new GitHub repository, click on the **Settings** tab.
2. Scroll down the left sidebar and click on **Pages**.
3. Under **Build and deployment**, look for "Branch". Change it from `None` to `main` (or `master`).
4. Click **Save**.
5. Within 1-2 minutes, GitHub will generate a live URL at the top of the Pages settings (e.g., `https://yourusername.github.io/sprintsense-web/`).
